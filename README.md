# Crabster Technology - Industrial IoT & Automation Website

Modern, responsive web platform for **Crabster Technology** (Industrial IoT, Panels & Automation — Coimbatore), designed and built directly from the complete set of design templates.

---

## 🛠️ Tech Stack

- **React 18** + **Vite 5** (Fast, modular, modern component-driven setup)
- **Tailwind CSS** (Configured with custom typography and brand colors matching the templates)
- **Lucide Icons** (Industrial, engineering & navigation iconography)
- **Google Fonts Inter & Caveat** (Clean editorial typography & handwritten brand logo)

---
